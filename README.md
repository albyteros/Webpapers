# Webpapers

A collection of live wallpapers built as standalone web pages. Each one is a single `index.html` with no build step and no dependencies. Open it in a browser, or point a web-wallpaper app (Plash, Lively Wallpaper, Wallpaper Engine's web type, etc.) at the file.

## WebpaperTemplate

A minimal starting point: a background that changes with the time of day and a clock. Helpful starting point
